Informasi API untuk Integrasi

Gunakan alamat (endpoint) berikut untuk mengambil data dari sistem monitoring ini dan menggunakannya di aplikasi lain. Semua endpoint mengembalikan data dalam format JSON.

Endpoint Chatbot AI (Memerlukan Kunci API)

POST /api/chatbot

Endpoint ini memungkinkan Anda berinteraksi dengan asisten AI. Anda harus menyertakan Kunci API sebagai Bearer Token di header Authorization.

Kunci API Platform Anda:

ABCDEFGIJKLMNOPQRSTUFWXYZ

Contoh Penggunaan (cURL):

curl -X POST http://127.0.0.1:5000/api/chatbot \
-H "Content-Type: application/json" \
-H "Authorization: Bearer ABCDEFGIJKLMNOPQRSTUFWXYZ" \
-d '{"question": "Berapa suhu air rata-rata kemarin?"}'

Untuk contoh penggunaan dengan JavaScript, Python, dan detail lainnya, silakan lihat dokumentasi lengkap.

Endpoint Data Real-Time

GET /api/monitoring

Endpoint ini menyediakan data sensor **terakhir** yang diterima. Tidak memerlukan kunci API.

Contoh Struktur Data:

{
    "connection": {"baudrate": 9600, "port": "COM3"},
    "converted": {"celsius": 28.5, "ph": 7.1, ...},
    "raw": {"air": 460, "level": 800, ...},
    "timestamp": "2025-09-28 14:30:00"
}

Endpoint Data Statistik

GET /api/statistics

Endpoint ini menyediakan data historis yang telah diolah (rata-rata, terendah, tertinggi) per hari. Tidak memerlukan kunci API.

Contoh Struktur Data:

{
    "2025-09-27": {
        "averages": { "celsius": 27.5, "ph": 7.2, ... }, ...
    },
    "2025-09-28": {
        "averages": { "celsius": 28.1, "ph": 7.1, ... }, ...
    }
}
