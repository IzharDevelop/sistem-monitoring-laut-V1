Dokumentasi Proyek PRAHU

Panduan Pengguna, Referensi API, dan Konfigurasi Perangkat Keras

1. Panduan Memulai Cepat

Ikuti langkah-langkah ini untuk menjalankan dan menggunakan aplikasi PRAHU.

  1. Login sebagai Admin: Buka aplikasi di browser. Anda akan disambut oleh halaman login. Masukkan username dan password yang valid (contoh: admin / admin).
  2. Konfigurasi Koneksi: Setelah berhasil login, Anda akan melihat halaman konfigurasi. Pilih Port Serial tempat perangkat Anda terhubung dan sesuaikan Baud Rate agar cocok dengan yang ada di kode perangkat keras Anda (umumnya 9600).
  3. Hubungkan: Klik tombol "Hubungkan". Jika berhasil, Anda akan otomatis diarahkan ke Dasbor Admin. Jika gagal, akan muncul pesan error untuk membantu Anda melakukan troubleshooting.

2. Anatomi Dasbor Admin

Dasbor admin adalah pusat kendali dan monitoring. Berikut adalah penjelasan setiap komponennya.

Status Overview

Bagian ini memberikan ringkasan status perahu secara cepat dan mudah dibaca.

  • Mesin: Menunjukkan apakah mesin sedang MAJU atau STOP.
  • Konveyor: Menunjukkan apakah sistem konveyor sedang ON atau OFF.
  • Arah Belok: Menampilkan sudut belok perahu saat ini dalam derajat.
  • Kemiringan: Menunjukkan kemiringan perahu (KIRI, KANAN, atau CENTER).

Panel Kontrol

Gunakan tombol-tombol ini untuk mengirim perintah langsung ke perahu.

Visualisasi Sensor & Data

  • Grafik Sensor: Empat grafik menampilkan data pH, polusi udara, suhu, dan level air secara real-time.
  • Live Serial Monitor: Menampilkan log data mentah yang diterima dari port serial.
  • Real-Time Raw Values: Tabel yang menunjukkan nilai mentah terakhir dari semua parameter sensor.

3. Referensi API

Aplikasi ini menyediakan beberapa endpoint API untuk mengakses data secara terprogram.

GET /api/monitoring

Mengembalikan data sensor dan status koneksi terakhir dalam format JSON.

GET /api/statistics

Mengembalikan rekapitulasi statistik (rata-rata, tertinggi, terendah) dari data sensor yang dikelompokkan per hari.

POST /admin/send_command

Mengirim perintah kontrol ke perangkat. Endpoint ini memerlukan login admin.

POST /api/chatbot

Mengirim pertanyaan ke asisten AI dan menerima jawaban berdasarkan data telemetri dan basis pengetahuan. Endpoint ini memerlukan autentikasi menggunakan API Key.

  • URL: http://127.0.0.1:5000/api/chatbot
  • Method: POST
  • Headers:
    • Content-Type: application/json
    • Authorization: Bearer ABCDEFGIJKLMNOPQRSTUFWXYZ
  • Body (JSON): 
    {
    "question": "Berapa suhu air laut saat ini?"
}

Contoh Penggunaan:

curl -X POST http://127.0.0.1:5000/api/chatbot \
-H "Content-Type: application/json" \
-H "Authorization: Bearer ABCDEFGIJKLMNOPQRSTUFWXYZ" \
-d '{
    "question": "Apa dampak perubahan iklim bagi laut?"
}'
const apiKey = 'ABCDEFGIJKLMNOPQRSTUFWXYZ';
const question = 'Apa dampak perubahan iklim bagi laut?';

fetch('http://127.0.0.1:5000/api/chatbot', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${apiKey}`
    },
    body: JSON.stringify({ question: question })
})
.then(response => response.json())
.then(data => {
    console.log(data.answer);
})
.catch(error => {
    console.error('Error:', error);
});
import requests
import json

api_key = 'ABCDEFGIJKLMNOPQRSTUFWXYZ'
question = 'Apa dampak perubahan iklim bagi laut?'
url = 'http://127.0.0.1:5000/api/chatbot'

headers = {
    'Content-Type': 'application/json',
    'Authorization': f'Bearer {api_key}'
}

data = {
    "question": question
}

try:
    response = requests.post(url, headers=headers, data=json.dumps(data))
    response.raise_for_status()  # Raise an exception for bad status codes
    
    result = response.json()
    print(result.get('answer'))

except requests.exceptions.RequestException as e:
    print(f"Error: {e}")

4. Panduan Perangkat Keras

Agar aplikasi dapat berfungsi dengan benar, perangkat keras Anda (misal: Arduino) harus mengirimkan data melalui serial dengan format yang tepat.

Format Data Serial

Data harus dikirim sebagai satu baris teks berisi **9 nilai integer yang dipisahkan koma**, diakhiri dengan karakter baris baru (newline). Gunakan fungsi Serial.println().

[TDS],[Udara],[Suhu],[GiroKanan],[GiroKiri],[LevelAir],[Konveyor],[Belok],[Maju]
